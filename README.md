# Gym Form Tracker 🏋️

## 📌 Description
This is a Computer Vision project that detects gym exercise form and counts repetitions using a webcam.

## 🚀 Features
- Real-time pose detection
- Rep counting (bicep curls)
- Uses MediaPipe and OpenCV

## 🛠 Requirements
- Python 3.x
- Webcam

Install dependencies:
pip install -r requirements.txt

## ▶️ Run
python main.py

## 📷 Output
Tracks body movement and displays rep count on screen.
